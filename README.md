---

## What this is

This is the **public-facing, share-safe** front door of the SheMesh Tribe LLC ecosystem.

It provides practical tools for ordinary people, households and communities to:

- Learn and plan
- Prepare for work and resilience
- Protect digital and household safety
- Organise local notes and progress
- Participate in simple community exchange
- Grow skills and readiness

Everything runs in the browser. **No account. No remote database for core features. Progress stays on your device.**

---

## What users can do

| Tool | Purpose |
|------|---------|
| **Resilience Audit** | Interactive checklist with live progress. Saved locally. |
| **Offline AI Butler** | Template-based planning helper (PLAN, CHECKLIST, MAKE IT SIMPLE, STUDY, JOB). Fully local — no AI API. |
| **Evidence Locker** | Local notes (title, date, note). Export as JSON. Delete anytime. |
| **Safety Centre** | General digital and practical safety reminders. |
| **Learning Path** | 8-step interactive pathway with local progress. |
| **Community Exchange** | Local-only board for Needs, Skills, Resources, Ideas. |
| **13 Public Hubs** | Entry points that route into the tools above. |

## Privacy model

- No account required  
- No remote database for core functionality  
- All progress, notes and exchange entries stored in **browser localStorage**  
- Export and delete capabilities provided  
- No analytics trackers  
- No advertising trackers  
- No third-party tracking scripts

## Offline-first / PWA

- `manifest.webmanifest` for installability  
- `sw.js` service worker caches core files  
- Core functionality works without a network after first load  

Enable **GitHub Pages** (Settings → Pages → Source: **GitHub Actions**) to publish the site from this repository.

## How to use

1. Open `index.html` in a modern browser, or serve the folder with any static file server.  
2. Or visit the GitHub Pages URL once Pages is enabled.  
3. All tools work immediately. No login.  
4. Progress is saved on the device you are using.
