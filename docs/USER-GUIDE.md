# User Guide — SheMesh Tribe LLC Public Ecosystem

A practical guide for ordinary users.

---

## Navigating the homepage

- **Header**: Brand name and menu (Home, 13 Hubs, Tools, Learning, Community, About).  
- On small screens, open the menu with the button in the top-right.  
- **Hero**: Tagline and two buttons — “Start with Tools” and “Explore 13 Hubs”.  
- Scroll or use the menu to jump to any section.  

---

## Using the 13 Hubs

Each hub card describes a practical area (digital skills, safety, food, employment, etc.).

Tap or click a hub card. You will be taken to the relevant tool or section:

- Many hubs open the **Offline AI Butler**, **Resilience Audit**, **Safety Centre**, **Learning Path** or **Community Exchange**.

---

## Resilience Audit

1. Go to **Tools → Resilience Audit**.  
2. Tick each statement that is true for you.  
3. Watch the progress bar and percentage update live.  
4. Your ticks are saved on this device (browser localStorage).  
5. Use **Reset checklist** to clear everything and start again.  

No account is needed.

---

## Offline AI Butler

1. Go to **Tools → Offline AI Butler**.  
2. Choose a mode: **PLAN**, **CHECKLIST**, **MAKE IT SIMPLE**, **STUDY** or **JOB**.  
3. Fill in the fields that appear.  
4. Press **Show template**. A structured summary appears below.  
5. Press **Clear** to empty the form and the output.  

This helper uses built-in templates only. It does **not** call any external AI service and does not need an API key.

---

## Evidence Locker

1. Go to **Tools → Evidence Locker**.  
2. Read the warning: never store passwords, PINs, card numbers, API keys, recovery codes or private keys.  
3. Enter a **Title**, **Date** and **Note**.  
4. Press **Add record**.  
5. Records appear in a list. You can **Delete** individual records.  
6. **Export JSON** downloads a file of all local records.  
7. **Delete all local data** removes every record on this device (confirmation required).  

This is a local note tool only. It is **not** a legally secure evidence-management system.

---

## Learning Path

1. Go to **Learning**.  
2. Work through the 8 steps. Tick each one as you complete it.  
3. Progress is saved on this device.  
4. Use **Reset progress** to clear the ticks.  

---

## Community Exchange

1. Go to **Community**.  
2. Choose a type: Need, Skill, Resource or Idea.  
3. Write a short description.  
4. Press **Add entry**.  
5. Entries appear in a list. Delete individual ones or **Clear all entries**.  

Everything stays on your device. This is not a public social network and has no remote backend.

---

## Safety Centre

Read the general reminders about verifying requests, protecting documents, strong passwords, MFA, cautious links and using professional services when needed.

This is general information only — not a substitute for professional legal, medical, financial or emergency advice.

---

## Offline behaviour

- After the first successful load, core files are cached by the service worker.  
- You can continue using the tools without a network connection (on the same device/browser).  
- Progress already saved in localStorage remains available offline.  

---

## Privacy

- No account is required.  
- No remote database is used for core features.  
- Progress, notes and exchange entries live in your browser’s local storage on this device.  
- You can export (Evidence Locker) and delete your local data.  
- No analytics or advertising trackers are included.  

Clearing browser data or using a different device/browser means you will not see the same local progress.

---

This application deliberately does **not** contain proprietary algorithms, trade secrets or confidential internal systems of SheMesh Tribe LLC.

It is designed so that an ordinary person can use practical tools without needing knowledge of any internal architecture.
